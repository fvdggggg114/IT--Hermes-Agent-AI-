架构和工具都理解之后，最后一步是把 Hermes Agent 变成 7×24 小时稳定运行的数字员工。部署选址、安全边界和集成方案，决定了它能否从“能用”走向“可靠”。

部署方案的选择逻辑
Hermes Agent 支持本地部署和云端部署两条路径。本地支持 Windows（WSL2）、macOS 和 Linux，适合对数据隐私要求极高的场景。云端部署方面，阿里云提供轻量应用服务器、ECS 和计算巢三种方案，搭配官方预装镜像可一键完成部署。百度智能云轻量应用服务器同样提供 Hermes 镜像。

选择部署方案时需权衡三个因素：数据敏感度决定是否必须本地部署；使用频率决定云端资源配置档位；团队运维能力决定是选一键部署还是手动配置。对于大多数个人和中小团队，云端轻量应用服务器是性价比最高的起点。

安全模型：纵深防御的每一层
Hermes Agent 采用纵深防御安全模型，覆盖从命令审批到容器隔离的每一层边界。第一层是危险命令审批——针对破坏性操作设置人工审核环节，确保 Agent 不会在无人值守时执行不可逆操作。第二层是容器隔离——支持 Docker、Singularity、Modal 等多种沙箱后端，Agent 执行的 Shell 命令落在沙箱内而非宿主机文件系统。

第三层是 MCP 凭据过滤——对 MCP 子进程进行环境变量隔离，防止凭据泄露。第四层是用户授权——通过允许列表和 DM 配对机制控制谁可以访问 Agent。此外，所有 API Key 存储在 ~/.hermes/.env 中，文件权限为 0600（仅所有者可读写），目录权限为 0700。

消息平台集成与企业落地
数字员工的价值在于“无处不在”。Hermes Agent 通过统一网关支持 20 多个消息平台集成，包括微信、企业微信、飞书、钉钉、Telegram、Discord、Slack、WhatsApp 等。以企业微信集成为例，需要在企业微信管理后台创建机器人，获取密钥后写入 Hermes 配置，即可实现持续交互与任务调用。

在 Microsoft 365 生态中，Hermes-A365 插件提供了两条集成路径：作为 AI Teammate 出现在 M365 租户目录中，或作为 Custom Engine Agent 接入 Copilot Chat 和 Office 侧面板。企业级用户还可将 Hermes 接入生产系统，例如中原油田储气库管理中心基于 Hermes 开发了“未来Pro智能体”，整合超过 50 万条专家知识经验用于设备检修提醒和新人培训。

从部署到持续运行
定时任务是数字员工“自主工作”的关键能力。Hermes 通过单一 cronjob 工具暴露 cron 管理能力，支持自然语言调度和标准 cron 表达式，任务可单次执行、按周期执行或按间隔执行。为避免失控的调度循环，cron 执行内部禁用了 cron 管理工具。
